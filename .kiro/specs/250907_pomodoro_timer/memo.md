# ポモドーロタイマー機能 要件メモ

## 1. 基本機能

- **ポモドーロサイクル**:
    - **作業時間**: 25分間のタイマーを計測する。
    - **休憩時間**: 5分間のタイマーを計測する。
    - 上記の「作業時間 → 休憩時間」を1サイクルとする。
- **サイクルカウンター**: 現在のサイクル数を表示する。
- **自動切り替え**:
    - 作業時間が終了したら、アラームを鳴らし、自動的に休憩時間タイマーを開始する。
    - 休憩時間が終了したら、アラームを鳴らし、次のサイクルの作業時間タイマーを開始する準備をする。

## 2. ユーザー操作

- **スタート/ストップボタン**:
    - タイマーを開始する。
    - 計測中にタイマーを一時停止する。
    - 一時停止中にタイマーを再開する。
- **リセットボタン**:
    - 現在のタイマー（作業中または休憩中）をリセットし、初期状態（作業時間の25分）に戻す。
    - サイクルカウンターもリセットされる。

## 3. UI/UX

- **タイマー表示**:
    - 残り時間を「分:秒」形式で表示する。（例: "24:59"）
    - 現在が「作業時間」か「休憩時間」か分かるように表示する。
- **サイクル表示**:
    - 現在のサイクル数を表示する。
- **アラーム**:
    - 各タイマー終了時に音で通知する。
- **コントロールボタン**:
    - スタート/ストップボタン
    - リセットボタン
