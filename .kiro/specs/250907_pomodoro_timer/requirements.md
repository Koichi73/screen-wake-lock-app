# 要求仕様書：ポモドーロタイマー機能

## はじめに

このドキュメントは、既存の「画面スリープ防止Webアプリケーション」に対するポモドーロタイマー機能の追加要求仕様を定義します。この機能により、ユーザーは効率的な時間管理手法であるポモドーロテクニックを実践でき、作業と休憩のサイクルを管理しながら画面のスリープを防止できます。

## 要件

### 要件1

**ユーザーストーリー:** ユーザーとして、25分の作業時間と5分の休憩時間を自動で管理するポモドーロタイマーを使用したい。これにより、効率的な時間管理を実践し、集中力を維持したい。

#### 受け入れ基準

1. WHEN ユーザーがポモドーロタイマーページ（`/pomodoro`）にアクセスする THEN システムは25分の作業時間タイマーを初期状態として表示する
2. WHEN 作業時間タイマーが終了する THEN システムはアラーム音を鳴らし、自動的に5分の休憩時間タイマーを開始する
3. WHEN 休憩時間タイマーが終了する THEN システムはアラーム音を鳴らし、次のサイクルの作業時間タイマーを開始する準備状態にする

### 要件2

**ユーザーストーリー:** ユーザーとして、タイマーの開始、一時停止、再開、リセットを簡単に操作したい。これにより、自分のペースでポモドーロテクニックを実践したい。

#### 受け入れ基準

1. WHEN ユーザーがスタートボタンをクリックする THEN システムは現在のタイマー（作業時間または休憩時間）をカウントダウン開始する
2. WHEN タイマーが動作中にユーザーがストップボタンをクリックする THEN システムはタイマーを一時停止し、ボタンを「再開」表示に変更する
3. WHEN タイマーが一時停止中にユーザーが再開ボタンをクリックする THEN システムはタイマーを再開し、ボタンを「ストップ」表示に変更する
4. WHEN ユーザーがリセットボタンをクリックする THEN システムは現在のタイマーを25分の作業時間に戻し、サイクルカウンターを1にリセットする

### 要件3

**ユーザーストーリー:** ユーザーとして、現在の状態（作業中か休憩中か）、残り時間、サイクル数を明確に把握したい。これにより、進捗を確認しながら効率的に作業を進めたい。

#### 受け入れ基準

1. WHEN タイマーが表示されている THEN システムは残り時間を「MM:SS」形式で表示する
2. WHEN 作業時間中である THEN システムは「作業時間」であることを視覚的に明示する
3. WHEN 休憩時間中である THEN システムは「休憩時間」であることを視覚的に明示する
4. WHEN タイマーが動作している THEN システムは現在のサイクル数を「サイクル X」として表示する

### 要件4

**ユーザーストーリー:** ユーザーとして、タイマー終了時に音声通知を受け取りたい。これにより、他の作業に集中していても時間の切り替わりに気づくことができる。

#### 受け入れ基準

1. WHEN 作業時間タイマーが0:00に到達する THEN システムはアラーム音を再生する
2. WHEN 休憩時間タイマーが0:00に到達する THEN システムはアラーム音を再生する
3. WHEN アラーム音が再生される THEN システムは適切な音量で3秒間音を鳴らす

### 要件5

**ユーザーストーリー:** ユーザーとして、ポモドーロタイマー使用中に画面がスリープしないようにしたい。これにより、タイマーの進行状況を常に確認でき、中断されることなく作業を続けられる。

#### 受け入れ基準

1. WHEN ユーザーがポモドーロタイマーページにアクセスする THEN システムは既存のWake Lock機能のトグルボタンを表示する
2. WHEN ユーザーがWake Lockを有効化する THEN システムは画面のスリープを防止し、タイマー動作中も継続する
3. WHEN ユーザーがポモドーロタイマーページから離れる THEN システムはWake Lockを自動的に解除する
4. WHEN ブラウザがWake Lock APIをサポートしていない THEN システムは既存の互換性警告を表示する

### 要件6

**ユーザーストーリー:** ユーザーとして、異なるデバイス（スマートフォン、タブレット、デスクトップ）でポモドーロタイマーを使用したい。これにより、どの環境でも快適に時間管理を行いたい。

#### 受け入れ基準

1. WHEN ユーザーがモバイルデバイスでアクセスする THEN システムは画面サイズに適したレイアウトでタイマーを表示する
2. WHEN ユーザーがデスクトップでアクセスする THEN システムは大きな画面を活用した見やすいレイアウトでタイマーを表示する
3. WHEN 画面の向きが変更される THEN システムは新しい向きに適応したレイアウトに自動調整する
